## 整体架构

```
输入内容 → 路由（判断类型） → 选择对应 Aligner
                                     │
                          三视角评审团（定性）
                          ┌──────────┼──────────┐
                          急躁哥    逻辑控     视听专家
                                     │
                          Script / Storyboard / Prompt-Aligner（定量）
                                     │
                          综合报告 → 🔴🟡🟢 分级优化清单
```

## 路由逻辑

根据输入内容自动选择审核模式：

| 输入特征 | 路由到 | 示例 |
|---------|--------|------|
| `## Scene` / `## Dialogue` / 剧本格式 | Script-Aligner | `script/EP-XX.md` |
| `\| # \| Time \| Shot \| Camera \|` / 分镜表格 | Storyboard-Aligner | `storyboard/EP-XX.md` |
| 角色外观描述 / `--image` / 参考图 / 风格关键词 | Prompt-Aligner | `prompts/EP-XX.md` |
| 标题/大纲/人设/视频成片 | 三视角定性 + 对应 Aligner | 用户发全剧 |
| 无法判断 | 先用三视角定性，再问用户 | 自由格式 |

## 一、三视角评审团（定性层）

> 评审团提供"哪里不好 + 为什么"，Aligner 提供"具体扣了多少分"。

### 角色定义

| 视角 | 关注点 | 容忍度 |
|------|--------|--------|
| **急躁哥** (Impatient Bro) | 节奏、爽点、反转 | 极低（没冲突就划走） |
| **逻辑控** (Logic Master) | 逻辑、类型定位、差异化、世界观一致性 | 低（逻辑硬伤不可接受） |
| **视听专家** (Visual Expert) | AI制作可行性、视觉一致性、成本预估 | 中（关注技术实现） |
| **编剧同行** (Writer Peer) | 创作意图、角色弧光完整性、情感真实性 | 不评分，只写 notes |
| **编剧同行** (Writer Peer) | 创作意图、规则打破的合理性、叙事选择 | 高（先理解意图再判断，不急着判对错） |

**编剧同行视角（v3.8 ⭐ 新增）**：核心问题"这个选择是有意为之还是无意出错？"——不评分只写notes，区分"知道规则但选择打破"和"不知道规则所以出错"。

### Industry Ground Truth (基于真实数据)

这些洞察来自 2025-2026 年海外短剧行业数据：

**什么有效 ✅**
| 洞察 | 来源 |
|------|------|
| 越简单直接越受欢迎 — 玛丽苏 > 复杂剧情 | 之桃影视制片人朱古力 |
| 声音是付费驱动因素 — 气泡音/骚讲话 | 朱古力实地观察 |
| 女频全球通吃 — 核心受众是拉丁裔/东南亚社会下层女性 | 36氪 2025Q1 |
| 黑帮 + 狼人题材火爆 — "强制爱 + 身份觉醒"组合 | 2025年2月市场数据 |
| 情感陪伴 > 剧情深度 — 观众要的是情绪价值，不是逻辑 | 之桃影视 2024 复盘 |
| **Beat Engine (Hook→Friction→Spike→Button) 是欧美爆款核心结构** | Filmustage 2026, ReelShort制作方 |
| **Premise-Driven Conflict > 场景驱动冲突** — 设定自带冲突93集不崩 | Bound by Honor (373M views) |
| **Dramatic Irony 是最强留存机制** — 观众知道角色不知道 | Miss You After Goodbye (双平台#1) |
| **对白=行动，Subtext>Text** — 角色不解释感受，观众推断 | Filmustage 2026 |
| **3-7-21 付费墙 Block 分层** — >50%付费转化率 | ReelShort/DramaBox 2025 |
| **竖屏=特写优先** — vertical drama lives in faces, not locations | Filmustage 2026 |
| **Cliffhanger 写到秒** — Button 在55-58秒freeze-frame最优 | ReelShort工程团队 |

**什么踩坑 ❌**
| 踩坑 | 原因 |
|------|------|
| 悬疑/强剧情路线行不通 | 观众"不花钱也能忍" |
| 精致但不爽 — 百万美金制作但数据不好 | 竖屏限制 + 观众耐心有限 |
| 闪婚失忆认不出老公 | 海外结婚证没有照片 |
| 自助洗衣房场景 | 海外不常见 |
| 过度"虐女"情节 | 海外女性观众反感 |
| **Hook 写成铺垫**（"她走进房间"而不是"他掐住她的下巴"） | 3秒定帧失败，观众划走 |
| **Friction 写成情绪暗示**（"气氛紧张"而不是"他把文件摔在桌上"） | 不可拍摄，画面没在干活 |
| **Spike 依赖音效**（静音后 spike 消失） | 那是音量不是冲击 |
| **Button 解释太多**（"她惊恐地发现..."而不是切在她睁大眼睛的瞬间） | 比安全早2秒切断 |
| **场景驱动冲突**（每集临时加误会/谎言/巧合） | Premise 不自带冲突，93集撑不住 |

### 节奏公式（行业验证 v4.1 ⭐ Beat Engine 化聚）

```
Hook(引爆) → Friction(可拍摄冲突) → Spike(重新定价) → Button(问题前切断)
```

> 行业原话："Draft your timestamp skeleton first — 0:00 ignition, 0:32 first jolt, 1:18 spike, 1:50 button — then write the dialogue that carries those moments." (Filmustage 2026)
> ReelShort 工程团队发现：freeze-frame 在 55-58 秒时留存率最高，编剧现在写到秒而不是写到页。

### 评审框架（三视角定性）

#### 评审剧本

| 维度 | 急躁哥 | 逻辑控 | 视听专家 |
|------|--------|--------|----------|
| 核心问题 | 有没有爽点和情绪陪伴 | 节奏卡点是否准确、动机是否合理 | 场景成本、技术可行性 |
| 关键指标 | 3 秒钩子、10 秒爽点、结尾钩子 | 每 30 秒新信息、人设一致性 | 每集 1-3 分钟、竖屏适配 |
| 差评信号 | 平铺没有冲突、结尾无悬念 | 角色行为无动机、信息缺失 | 场景过多、转场不自然 |
| **Beat Engine（v4.1 ⭐）** | Hook 3秒有没有引爆？Button 有没有切断？ | Friction 是可拍摄冲突还是情绪暗示？Spike 静音测试？ | Hook 画面能否3秒定帧？ |
| **Dramatic Irony（v4.1 ⭐）** | "我知道她不知道"的感觉有没有？ | EP2-3 观众信息优势建立了吗？差距在维持吗？ | 角色发现真相的时机是否在付费墙后？ |
| **对白（v4.1 ⭐）** | 对白有没有让我想打人/哭/笑？ | 前2行进冲突了吗？解释感受了吗？ | 长独白→拇指划走 |

#### 评审分镜

| 维度 | 急躁哥 | 逻辑控 | 视听专家 |
|------|--------|--------|----------|
| 核心问题 | 画面是否有冲击力 | 分镜逻辑是否连贯 | 运镜是否可执行、Seedance 限制 |
| 关键指标 | 每个镜头有情绪信号 | 场景切换有理由 | 每镜头 1 种运镜、慢动作优先 |
| 差评信号 | 空镜头、无表情、画面呆板 | 时序混乱、场景跳跃 | 运镜过多、双人互动（易翻车） |
| **Beat Engine 视觉（v4.1 ⭐）** | Hook=最炸画面？Spike=静音也有冲击？ | Button=定格在表情/动作，不是解释完才切 | Spike画面是否"重新定价"之前信息？ |

## 二、三专用 Aligner（定量层）

每个 Aligner 独立 100 分制，≥80 PASS / 70-79 ⚠️ / ≤70 FAIL。

### A. Script-Aligner（审剧本）— 100 分

**前置：确认目标市场，整个审核的"尺子"跟着调。**

#### 区域适配矩阵

| 区域 | 钩子标准 | 情绪表达偏好 | 节奏容忍 | 文化雷区 | **Beat Engine（v4.1 ⭐）** | **Premise 要求（v4.1 ⭐）** | **Dramatic Irony（v4.1 ⭐）** |
|------|---------|-------------|---------|---------|----------------------|----------------------|----------------------|
| **欧美** | 2秒进冲突 | 爆炸式（"I want you to suffer!"） | 极低（5秒没爽点走人） | ①GLBT+未成年+永久身体改变组合 ②宗教隐喻过重 ③种族刻板印象 ④美化奴隶制/殖民 ⑤过度血腥无意义 | Hook=引爆（3秒定帧），Friction=可拍摄冲突，Spike=静音测试，Button=问题前切断 | 必须内建冲突（Enemies-to-lovers/Forbidden proximity/Power imbalance/Arranged circumstance） | EP2-3建立观众信息优势，维持差距到付费墙后 |
| **日韩** | 5秒氛围铺垫可接受 | 克制+内心戏 | 中等（能接受10秒情绪积累） | ①独岛/竹岛领土争议 ②美化殖民历史 ③天皇/皇室嘲讽 ④强制征用美化 ⑤等级/权力关系敏感 ⑥过度暴力需缓冲 | Hook允许氛围铺垫，Friction可含内心戏 | 允许场景驱动冲突（日韩擅长细腻积累） | 可用可不用，日韩更依赖氛围+克制 |
| **国内** | 2秒打脸 | 直白+反转 | 低（3秒没冲突划走） | ①警察/军人负面形象 ②穿越到现代当官 ③血腥暴力/恐怖过度 ④封建迷信宣扬 ⑤历史虚无主义 ⑥涉及政治人物/事件 ⑦价值观导向 | Hook=打脸/反转，Friction=爽感冲突 | 霸总/玛丽苏=Power imbalance，但更极端化 | 较少使用，国内观众更爱直接反转 |
| **东南亚** | 3秒情感+冲突 | 含蓄但有爆发点 | 低 | ①伊斯兰饮食禁忌（猪肉/酒精画面） ②先知/宗教嘲讽 ③女性暴露着装（伊斯兰地区） ④宗教冲突场景 ⑤赌博/博彩 ⑥家族伦理/辈分敏感 | Hook=情感冲击，Friction=家庭/社会冲突 | 家族伦理+辈分=天然Premise | 较少使用，更依赖情感共鸣 |

#### 导演覆盖机制（v3.8 ⭐ 新增）

> Aligner输出三色判定：🟢Green（放行）/ 🟡Yellow（警告，可忽略需写理由）/ 🔴Red（硬拦，部分可覆盖）

**类型适配说明（v4.1 ⭐ 更新）**：
- **核心冲击力**：所有类型统一12分（爆款第一维度，不可妥协）
- **Beat Engine**：revenge/forced_love/mystery 统一10分（节奏即产品），甜宠/玛丽苏8分（允许更慢）
- **Dramatic Irony**：mystery 最高(12)——悬疑核心机制；forced_love(8)——gaslighting/权力不对等；revenge(6)——复仇有但非核心
- **对白=行动**：甜宠/玛丽苏(8)——对白是核心驱动；revenge/forced_love/mystery(6)——画面也扛活
- **revenge**：冲突强度(12)+Beat Engine(10)双高，开局必须暴力/打脸，Premise=Enemies-to-lovers
- **forced_love**：核心关系(8)+Dramatic Irony(8)双高，Premise=Power imbalance/Forbidden proximity
- **sweet_romance**：核心关系(10)+对白=行动(8)双高，冲突偏误会/吃醋，Premise=Forbidden proximity
- **mary_sue**：节奏/平台(10)+对白=行动(8)双高，爽点密度最高，Premise=Power imbalance
- **mystery**：悬念钩子(12)+Dramatic Irony(12)双高，Premise=Dramatic Irony本身即产品

#### 🔥 叙事钩子等级表（v3.5 ⭐ 新增）

> 源自叙事钩子 10 级体系。编剧写 Cliffhanger 时标注类型，Aligner 审核时检查强度是否匹配当前集阶段。

| 等级 | 类型 | 核心原理 | 短剧示例 |
|------|------|---------|---------|
| 1 | **信息钩子** | 信息缺口 → 人脑想补全 | "名册最后一页写着..." |
| 2 | **异常钩子** | 反常事 → 人心好奇 | "吸血鬼居然流了眼泪" |
| 3 | **危险钩子** | 威胁 → 生存本能 | "Carmilla 獠牙逼近颈动脉" |
| 4 | **欲望钩子** | 观众想看角色得到/失去什么 | "他终于说出了那三个字" |
| 5 | **关系钩子** | 核心关系面临转折/破裂 | "两个敌人发现彼此是同父异母" |
| 6 | **羞耻钩子** | 角色被暴露、被看穿、被羞辱 | "所有人都知道了她的秘密" |
| 7 | **不可逆钩子** | 发生了回不去的事 | "父亲撕毁了名册关键页" |
| 8 | **误判钩子** | 观众/角色以为 A，其实是 B | "以为是救赎，其实是陷阱" |
| 9 | **后果链钩子** | 一个后果引发连锁反应 | "Laura 变身→被父亲发现→赶出家门→流落街头" |
| 10 | **复合钩子** | 同时触发 2-3 种钩子类型 | 身份暴露(羞耻6)+撕毁名册(不可逆7)+父亲破门(危险3)+瞳孔变色(异常2) |

**钩子选择原则（动态，不套用公式）**：

先判断本集内容类型（囚禁集/对峙集/闪回集/揭示集/高潮集/日常铺垫...），再选最匹配的钩子类型：

| 集类型 | 推荐钩子方向 | 示例 |
|--------|------------|------|
| **揭示集**（身份/真相揭晓） | 异常(2) + 误判(8) | "以为是人，其实是吸血鬼" |
| **对峙集**（正面对决） | 危险(3) + 不可逆(7) | "刀架在颈上，决定无法收回" |
| **关系转折集**（情感/信任变化） | 关系(5) + 羞耻(6) | "他看到了不该看的" |
| **日常铺垫集** | 信息(1) + 欲望(4) | "日记最后一页缺了一角" |
| **高潮/结局集** | 后果链(9) → 复合(10) | 多个线索同时收束 |

**审核判定（动态评估）**：
- ✅ 钩子类型匹配本集内容，且让观众有"不看不行"的冲动 → 满分
- ⚠️ 钩子可用但强度偏弱（如高潮集只用了信息钩子）→ 扣 5 分
- ❌ 钩子与本集内容脱节（如日常集用了后果链却无前置铺垫）→ 扣 10 分
- ❌ 无类型标注 → 扣 3 分（编剧需写 `Hook: [类型名称+等级]`）

**核心原则**：10 级是**词汇表**不是公式。编剧根据本集实际情节选最适配的钩子，Aligner 审核时判断"这个钩子是否有效服务了这集的内容"，而不是"这集必须 N 级"。后期集倾向于高级钩子（情绪驱动）是因为付费转化需要，但如果本集就是铺垫性质，低等级钩子也能 PASS。

**v4.0 简单性原则（防通胀 ⭐）**：
- **能用单一的不用复合**："他撕了名册"（不可逆7）比"同时触发羞耻+不可逆+危险+异常"（复合10）更有冲击力——观众在1秒内只能消化一个核心情绪
- **能用低级的不用高级**：日常铺垫集用信息钩子(1)就够，不需要硬拉到危险(3)
- **复合钩子是高潮集的特权**：只有高潮/结局集才允许复合钩子(8-10)，其他集用单一钩子
- **等级通胀扣分**：复合钩子(8-10)用于非高潮集 → -5分

#### 🔥 Atmosphere 列常见错误（v3.3 ⭐ 2026-05-15 导演纠正）

- ❌ **写成情绪词**：如"恐怖压抑"、"暧昧紧张"、"悲伤回忆" — 这些属于 Description 列
- ✅ **写成物理环境**：如"深夜/雨/闪电"、"黄昏/阴/微光"、"室内/无窗/人工光"
- **根因**：Atmosphere 是 Lighting 列的前置条件。先知道"深夜+雨+闪电"，Lighting 才能据此推理光源（闪电冷白+烛火暖黄+暗角）。如果写了"恐怖压抑"，Lighting 无法从中推导出实际光源。
- **检查项**：Atmosphere 列中的词是否能在实际场景中"看到"（天气/时间/光线）而非"感觉到"（情绪）

#### 运镜可执行性分级（v3.8 ⭐ 新增）

| 级别 | 运镜类型 | AI遵循率 | 使用规则 |
|------|---------|---------|----------|
| 🟢 可靠 | static / slow_push / slow_pull / pan / tilt / top_down | >80% | 自由使用 |
| 🟡 有限 | handheld / orbit / zoom / dolly / low_angle / over_shoulder | 30-80% | 每集≤2个，必须写理由+标注备选方案 |
| 🔴 赌博 | complex_combo / whip_pan / crash_zoom / rack_focus / spin | <30% | 每集≤1个，必须标注"需人工替代方案" |

**分镜模板规则**：每集 🟢可靠运镜 ≥ 60%，🟡有限运镜 ≤ 2个/集（需写理由），🔴赌博运镜 ≤ 1个/集

#### 跨集视觉承接扣分规则（v3.9 ⭐ 新增）

> 前提：visual_continuity.md 存在且含上一集结尾视觉快照。如不存在（首集/旧项目），本维度跳过不扣分。

**扣分规则：**

- 运镜风格无理由跳变（上集手持→本集固定，同情绪场景）→ -2分
```

#### BGM/SFX节奏扣分规则（v4.1 ⭐ 新增）

```
- BGM无理由持续（整集同一段BGM无变化）→ -2分

#### Storyboard-Aligner 其他维度扣分规则（v4.1 ⭐ 补全）

```
- 节奏分层：无时长突变点（每镜时长均匀）→ -3分；信息过载（1秒塞2种情绪）→ -2分/处
- 景别层次：景别单一无变化（全特写或全中景）→ -3分；核心信息在非最优景别传达→ -2分
- 时空切换：闪回无衔接三件套（动作承接+视觉锚点+音效联动）→ -3分/处
- AI指令颗粒度：特效参数模糊（无位置/颜色/透明度）→ -2分/处；缺AI约束词→ -2分/处
- 情绪递进：情绪变化未被镜头语言"看见"→ -3分；转折点无运镜/光影对比→ -2分
```

**合理跳变的例外（不扣分）：**
- 时间跳跃（"X HOURS LATER"/"NEXT MORNING"）→ 色调/光源/服装可变
- 场景切换（从室内→室外）→ 色调/光源/运镜全部可变
- 情绪转折（角色从恐惧→决心）→ 运镜风格可变（手持→稳定）
- 闪回/梦境 → 一切可变，但需标注

① Frame 1: Carmilla画面左侧面向右 → ❌ 无理由位置跳变（-3分）
② Frame 1: 色调暖金 → ❌ 无理由色调跳变（-3分）
③ Frame 2: 卧室门关闭完好 → ❌ 场景物理不延续（-3分）
④ Frame 1: Laura=日装 → ❌ 服装不延续（-2分）

得分：10 - 3 - 3 - 3 - 2 = -1 → 0分（下限0）

```

## 三、综合工作流

### 单集审核流程

```
1. 用户发送内容 → 路由判断类型
2. 三视角评审团定性分析（急躁哥/逻辑控/视听专家）
3. 对应 Aligner 定量评分（Script/Storyboard/Prompt）
4. 交叉验证：定性问题 + 定量扣分 → 确认严重程度
5. 输出综合报告（定性吐槽 + 定量评分 + 🔴🟡🟢 优化清单）
```

### 全剧审核流程

```
1. 用户发送全剧三件套
2. 逐集跑对应 Aligner（可并行读文件，串行出报告）
3. 汇总全剧评分 → 通过/未通过集数统计
4. 集间衔接检查（Cross-Episode Continuity）
5. 输出全剧综合报告
```

### 审核→修改闭环

```
1. 🔴 必须修改 → 直接修改对应文件（write_file 全量重写）
2. 🟡 建议优化 → 修改或制作阶段处理
3. 🟢 锦上添花 → 制作阶段处理
4. 修改后重新跑对应 Aligner → 直到 ≥ 80 分
```

## 四、集间衔接检查（Cross-Episode Continuity）

| # | 检查项 | 典型断裂 |
|---|--------|---------|
| 1 | 开场回收上集结尾钩子 | 下集跳新场景，上集核心情绪被丢弃 |
| 2 | 角色动机连贯 | 上集"放下仇恨"，下集又冷酷复仇 |
| 3 | 悬念线索延续 | 上集铺垫的秘密，下集不再提起 |
| 4 | 角色状态一致 | 受伤角色下一集消失；觉醒能力重复"发现" |
| 5 | 场景位置合理 | 上集在 A 地，下集在 B 地，无过渡 |

**修复手法：**
- 下集前 5 秒必须接上集结尾
- 角色转变需要独白或台词解释"为什么"
- 闪回收拢形成情感闭环

## 短剧创作法则（v4.1 ⭐ 欧美爆款标准）

### 欧美爆款核心法则（不可违反）
- **Beat Engine**：每集按 Hook→Friction→Spike→Button 写，先写 timestamp skeleton 再写对白
- **Premise-Driven Conflict**：冲突内建于设定（Enemies-to-lovers/Forbidden proximity/Power imbalance/Arranged circumstance），不是场景制造
- **Dramatic Irony**：EP2-3建立观众信息优势，维持差距到付费墙后，这是比 cliffhanger 更强的留存机制
- **对白=行动**：每句对白要么推进冲突要么压力下揭示角色。角色不解释感受，Subtext>Text
- **竖屏=特写优先**：vertical drama lives in faces, not locations。特写/近景≥50%
- **Cliffhanger 写到秒**：Button 在55-58秒freeze-frame最优，比感觉安全早2秒切断

### 通用法则
- 每集必有冲突
- 节奏紧凑密集（3秒没冲突就划走）
- 爽点分布合理
- 人物动机清晰
- 伏笔埋设与回收完整
- **钩子匹配（v3.5 ⭐）** — 结尾 Cliffhanger 根据本集内容类型动态选择最适配的钩子（参考10级体系），不是按集数硬套等级。每集标注 `Hook: [类型+等级]`
- **短句驱动（v2.7 ⭐）** — 每个动作描述 ≤ 2 个分句，用独立短句替代复杂从句（*"her eyes soften"* > *"her eyes full of tenderness—nothing like the creature of the night"*）
- **情感锚点例外（v2.7 ⭐）** — 关键转折点（坦白、最终选择、生死瞬间）保留 1-2 句长描写作情感厚度
- **格式标准（v2.7 ⭐）** — 连续对话必须用 (CONT'D)，集末 FADE TO BLACK/OUT，全剧 FADE OUT + THE END
- **对话风格一致性（v2.7 ⭐）** — 根据项目风格（哥特古典/现代口语）设定，不混用

## 审核通过关键要素（v4.1 ⭐ 欧美爆款标准）

### 1. Beat Engine 四段完整（v4.1 ⭐ 最高优先级）
- ✅ **Hook**: 3秒定帧，引爆不是铺垫（"他掐住她的下巴"而不是"她走进房间"）
- ✅ **Friction**: 可拍摄冲突，不是情绪暗示（"他把文件摔在桌上"而不是"气氛紧张"）
- ✅ **Spike**: 静音测试通过（画面本身有冲击力，不依赖音效/配乐）
- ✅ **Button**: 在问题前切断，比感觉安全早2秒（切在睁大眼睛的瞬间，不是"她惊恐地发现..."）

### 2. Premise 自带冲突（v4.1 ⭐）
- ✅ **Enemies-to-lovers**: 角色天然对立，同框就有张力
- ✅ **Forbidden proximity**: 被迫共处但不该在一起，每次互动有重量
- ✅ **Power imbalance**: 权力不对等，每个指令/服从都有压力
- ✅ **Arranged circumstance**: 非自愿连接，没有选择本身就是冲突
- ❌ **场景驱动**: 每集临时加误会/谎言/巧合 → 93集撑不住

### 3. Dramatic Irony 活跃（v4.1 ⭐）
- ✅ EP2-3 建立观众信息优势（让观众看到主角看不到的事）
- ✅ 差距在维持（角色接近真相又拉回）
- ✅ 揭秘时机在付费墙后（观众为"她什么时候才发现"付费）
- ❌ 角色太快发现真相（Dramatic Irony 窗口太短）

### 4. 对白=行动（v4.1 ⭐）
- ✅ **冲突前2行就进入**
- ✅ **角色不解释感受** — 行动/否认/转移（"她把戒指扔进垃圾桶"而不是"I feel so betrayed"）
- ✅ **Subtext>Text** — 没说的比说了的更有力
- ✅ **短促为主** — 长独白极少有效

### 5. Face-slap 必须直接暴力
- ✅ **有效**: 泼红酒、推搡、抢物品、肢体冲突
- ❌ **无效**: 口头嘲讽、眼神不屑、翻白眼

### 6. 情感表达必须爆炸式
- ✅ **有效**: "我要你生不如死！"、"你是我的！"、"我找了你三年！"
- ❌ **无效**: "对不起"、"谢谢你"、"是你..."

### 7. Cliffhanger 必须明确
- ✅ **有效**: "Montana 见，我的真爱在那里等你"（发件人：Trent）
- ❌ **无效**: "她不知道，这次旅行将改变她的一生..."

### 8. 危机 - 救援结构
- ✅ **有效**: 巨熊拍向旋翼 → 变身救场 → 认出女主
- ❌ **无效**: 巨熊出现 → 消失 → 男人出现（缺乏戏剧张力）

### 9. 典型迭代次数
- **EP-01**: 通常 3 次（需要建立冲突模式+Premise验证）
- **EP-02**: 通常 4 次（需要建立人物关系+Dramatic Irony信息优势）
- **EP-03 后**: 通常 2-3 次（模式已建立）

### 6. 三件套工作流实战教训（2026-04-29 Carmilla项目验证）

**三件套 = 剧本(script/) + 分镜(storyboard/) + AI Prompts(prompts/)**

**第一稿高频翻车点（EP-02首次68分、EP-06首次70分）：**
| 翻车点 | 表现 | 修复后效果 |
|--------|------|-----------|
| 核心关系缺席 | Carmilla零出场/零台词/零情绪关联 | 加入闪回+矛盾心理台词（EP-06: 70→98） |
| 开局依赖上集回收 | 前3秒只是"上集紫纹门缝闪过" | 改为主动视觉冲击（EP-07 v2: 琥珀瞳孔发光开场） |
| 冲突无不可逆代价 | Carmilla闪避、紫纹自然扩散 | 父亲撕毁名册关键页（永久性信息丢失） |
| 无具体倒计时 | 只有"情况在恶化" | 明确"7天倒计时"+"3天内来人" |

| 正面镜头超标 | 50%+（EP-02 v1） | 用仰拍/俯拍/过肩替代，控制在≤35% |
| 角色外观漂移 | Carmilla瞳色在不同集之间变化 | **v2.0: 用 manifest.md 强制锁定** |

**分镜硬规则（写前检查，避免返工）：**
- 镜头数按集类型：氛围16-18 / 标准18-22 / 恐怖20-24 / 高潮22-25
- 单镜≤5秒（悬念慢推结尾最长10秒）

## Lighting 列写法规范 (v4.0 ⭐ 按集类型分层精度)

> **爆款原则**：3秒画面停留时间，观众只能消化1-2层光源信息。过度精度=浪费token+稀释冲击力。

**分层规则**：

| 集类型 | Lighting 精度 | 示例 | 理由 |
|--------|--------------|------|------|
| **氛围/日常/铺垫** | 一层（主光源） | "烛光" / "月光" / "日光" | 画面停留短，情绪简单，一层足够 |
| **标准/对峙** | 两层（主+补） | "暖黄烛光+冷蓝月光" / "顶灯+台灯" | 有情绪对比需要两层表达 |
| **恐怖/高潮/揭示** | 三层（主+补+效果） | "暖黄烛光(左前)+冷蓝月光(右补)+暗角压暗" | 关键时刻需要精确光源控制 |

**判断标准**：这镜的画面停留时间 × 情绪复杂度 是否需要三层？
- 停留≤2s 且 非高潮 → 一层
- 停留3-4s 且 有情绪对比 → 两层
- 关键转折/特效/高潮 → 三层

**三层完整写法**（仅高潮/恐怖/揭示集使用）：
- **主光 (Key Light)**: 主要光源+方向+颜色，如"暖黄烛光(镜前烛台,左前方)"
- **补光 (Fill Light)**: 辅助光源+颜色+方向，如"冷蓝月光(窗外,右侧)"
- **效果 (Effect)**: 暗角/轮廓光/体积光/自发光，如"暗角压暗+紫纹自发光(颈部)"
- **动态来源**: 根据 Scene 环境(室内/室外/白天/夜晚) + 情绪(恐惧→冷光/暧昧→暖光/回忆→褪色泛黄) 推理

## Atmosphere 列写法规范
- **物理天气/时间/光线环境**（非情绪感受），为 Lighting 列提供前置条件
- 格式：`时间+天气+天况`，用"/"分隔
- 示例: "夜晚/晴/月光" / "黄昏/阴/微光" / "深夜/雨/闪电" / "清晨/雾/散射光" / "白天/晴/直射阳光" / "室内/无窗/人工光"
- **动态来源**：根据 Scene 地点(室内/室外) + 剧情时间线(白天/夜晚/清晨/深夜) + 天气(晴/阴/雨/雪/雾/风) 推理
- ❌ 不要写情绪词如"恐怖压抑"、"暧昧紧张"——那些属于 Description 列
- ✅ 应该写物理环境如"深夜/雨/闪电"——这样 Lighting 列才能据此推理光源

## SFX 列写法规范
- 环境音 + 动作音，用"+"分隔
- 示例: "蜡烛噼啪+远处钟声" / "雨声+脚步声" / "翻书声" / "无"
- **动态来源**: 根据 Scene(环境音来源) + Action(动作音来源) 推理

## BGM 列写法规范
- 具体可执行的音乐描述，非情绪标签
- 示例: "低沉弦乐pad起" / "悲伤大提琴独奏" / "无" / "渐强" / "骤停" / "淡出"
- **动态来源**: 根据天气/时间变化 + 本集节奏曲线分配，开场hook用强音乐，对话段可"无"，cliffhanger渐强

## Shot Notes
- **核心冲击力**: [这集有没有一个让人"哇"的瞬间？简单直接>复杂精致]
- **Beat Engine 视觉**: [Hook画面/Friction动作/Spike冲击/Button定格，缺段标注]
- **竖屏特写优先**: [特写/近景占比XX%，全景/中景占比XX%，核心情绪是否在特写中传达]
- **节奏分层**: [开场/中段/结尾的节奏变化]
- **运镜匹配**: [恐怖段/悬念段/情感段对应的运镜策略，🟡运镜必须写理由]
- **景别层次**: [大特写→特写→近景→中景→全景的分布]
- **时空切换**: [场景转换方式+桥接手段]
- **灯光设计**: [全集灯光基调+关键镜头对比，如"暖黄vs冷蓝对比，紫纹自发光贯穿"]
- **音效设计**: [全集环境音主线+关键音效点，如"钟声作为恐惧触发器"]
- **音乐弧线**: [全集BGM起承转合，如"pad起→渐强→骤停(闪回)→弦乐爆发(cliffhanger)"]
- **AI指令颗粒度**: [特效/VFX参数，如紫纹=位置+颜色+脉动频率]
- **🟡运镜理由**: [每个🟡运镜为什么这个场景需要它，无理由=炫技]
- **情绪递进**: [情绪起点→终点，如何用镜头语言"看见"]
- **运镜种类统计**: 推/侧面/正面/仰拍/俯拍/跟拍/拉/摇 = [N]种
```

## 批量生产模式 (execute_code)

import os
