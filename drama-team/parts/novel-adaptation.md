# 阶段 0：小说 → 欧美短剧改编

> 输入为小说/Idea 时的第一阶段，产出**改编规划 + adaptation-map.md**，经人工确认后进入阶段1（大纲）。
> 这是"小说改成优质欧美短剧"的关键阶段：**取舍错了，后面 N 集全白写。**

---

## 0.1 输入类型识别

| 输入类型 | 处理方式 | 输出 |
|---------|---------|------|
| **完整小说**（文本/PDF） | 读全文 → 走 0.2-0.5 完整流程 | 改编规划 + adaptation-map → 阶段1 |
| **小说片段/大纲** | 直接分析 → 补全缺失信息 → 走 0.2-0.5 | 改编规划 → 阶段1 |
| **Idea描述**（文字/语音） | 澄清需求（风格/集数/单集时长/核心关系/结局）→ 扩写世界观 | 大纲草案 → 阶段1 |
| **灵感碎片**（图片/关键词） | 视觉分析 → 头脑风暴 → 生成Idea描述 | Idea描述 → 阶段1 |
| **好莱坞格式剧本** | 跳过阶段0-2，走 `parts/revision-workflows.md` 快速路径 | — |

## 0.2 原著分析清单（改编可行性判断）

逐项回答，写入改编规划开头：

1. **Premise 自检（一票否决项）**：原著核心设定是否命中/可改造为 4 种爆款 Premise 之一（Enemies-to-lovers / Forbidden proximity / Power imbalance / Arranged circumstance）？
   - 命中 → 直接提取为类型DNA
   - 可改造 → 写明改造方案（如"青梅竹马"→改为"联姻仇家"）
   - 都不行 → **向用户预警**：该小说需要大改才符合欧美短剧模型，确认再继续
2. **主线清点**：一句话概括主线冲突；冲突是否自带不可逆代价升级空间？
3. **支线清点**：列出全部支线 + 每条支线服务什么（主线推进/角色塑造/纯世界观）
4. **角色清点**：有名有姓角色总数；谁是核心 6 人（主角×2 + 反派 + 关键配角≤3）
5. **DI 潜力**：原著有没有"读者知道角色不知道"的信息差？没有 → 规划在 EP2-3 人工制造
6. **爽点密度**：原著每万字有几个打脸/反转/揭示？密度不足的区间标记为"需补写爽点"
7. **题材归类**：确定 `project_type`（revenge/forced_love/sweet_romance/mary_sue/mystery/vampire_werewolf），提取类型DNA（见 `parts/workflow.md`）

### 支线取舍判定（砍/合/留）

| 判定 | 规则 |
|------|------|
| **砍** | 支线只服务世界观、不推进主线冲突 → 删。欧美短剧没有"氛围支线"的空间 |
| **砍** | 支线角色与核心 6 人无强关系 → 连人带线删 |
| **合** | 两个配角功能重叠（都是"闺蜜/军师"）→ 合并为一人 |
| **合** | 支线冲突与主线冲突同类型 → 合并进主线作为升级节点 |
| **留** | 支线为付费墙后的揭秘供弹药（DI素材/伏笔）→ 保留并在伏笔规划表登记 |

**硬规则**：改编后有名有姓角色 ≤ 原著的 1/3，且 ≤ 10 人（核心 6 人 + 功能角色 ≤ 4 人）。

## 0.3 压缩公式（字数 → 集数 → 取材映射）

**集数决策**：
- 单集时长 = `ep_duration`（用户指定，默认 90s）；每集 90s ≈ 原著 1300-2000 字**有效冲突内容**（风景描写/心理独白/世界观解说不算），非 90s 按比例换算
- **商业规格：总集数 50-80 集（默认 60）**——付费集数量就是收入池，集数太少单用户 LTV 撑不起投流成本；12/24 集仅作 Demo/试水规格
- **压缩是双向的**：原著注水内容（风景/独白/解说）删掉；但有效冲突字数不足以撑起 50+ 集时，**爽点循环（打脸/反转/揭示）必须扩写复制**——用类型DNA的核心套路生成原创集（在 adaptation-map 标注"新增"）
- 集数对齐 Block 边界：免费区末集（paywall_ep-1）必须落在原著第一个大反转上

**三幕 → 付费墙 Block 映射（关键）**：

| 原著结构 | 短剧位置（默认 paywall_ep=8、60集） | 改编策略 |
|---------|---------|---------|
| 第一幕（建立） | **Block 1 免费区（EP1 ~ paywall_ep-1）** | 大幅压缩：原著铺垫全砍，EP-01 直接从激励事件的**冲突现场**开场，背景用 DI/闪回补 |
| 第二幕前半（冲突升级） | **Block 2 首付转化（paywall_ep ~ +3）** | 免费区末集（paywall_ep-1）Spike 必须是原著第一个大反转——"不看会亏"的信息重新定价，卡币点 |
| 第二幕后半（最低谷） | **Block 3 深度绑定（中段）** | 原著中段慢热区间在此消化；DI 差距不能缩小；爽点密度不足处补打脸/反转 |
| 第三幕（高潮+结局） | **Block 4 揭秘区（最后1/4）** | 原著高潮拆成多个揭示波次：DI 收窄→真相→新 Irony，不要一次揭完 |

**每集取材范围**：在 adaptation-map（见 0.5）中为每集标注对应原著章节。一集通常对应 1-3 章；原著一个大高潮章可拆 2-3 集（每集一个 Beat Engine 循环）。

## 0.4 中式 → 欧美转译（事前指导，不留给 Aligner 事后扣分）

### 套路映射表

| 中式网文套路 | 欧美短剧对应 | 转译要点 |
|-------------|-------------|---------|
| 打脸 | Public confrontation with irreversible cost | 不是"扇耳光解气"，是当众揭穿+社会性后果（解雇/离婚/逐出家族） |
| 隐藏身份大佬（龙王/战神） | Secret billionaire / Alpha in disguise | 欧美观众吃"身份反差"，不吃"军衔头衔"——权力要视觉化（豪宅/直升机/一通电话摆平） |
| 婆媳/宅斗 | In-law sabotage → 转为 Power imbalance | 弱化辈分伦理（欧美无感），强化利益/继承权冲突 |
| 雌竞抢男人 | **保留反派，改写动机** | 恶毒女配/绿茶未婚妻是 ReelShort 爆款标配反派——观众反感的是"女主为男人失智"，不是女性反派本身；给对手独立动机（利益/事业/家族） |
| 忍辱负重媳妇 | 必须改 | 女主必须有自主选择权和反击线——被动挨打的女主在欧美是差评核心源 |
| 失忆 | **作主 premise 可整剧用**（amnesia wife 类）；作中途转折工具才限每剧 ≤1 次且需前置伏笔 | 欧美竖屏高频主设定，不是禁忌 |
| 车祸/滴血认亲 | 保留但降频 | 每剧 ≤1 次，且需前置伏笔支撑 |
| 修仙/系统/金手指 | 转为 supernatural（狼人/吸血鬼/女巫） | 欧美没有修仙心智；等级体系映射为 Pack rank / Coven hierarchy |
| 多年后携子归来 | Second-chance + secret baby | 欧美验证过的高转化套路，可直接用 |
| 追妻火葬场 | **Groveling hero** | 欧美 romance 高付费桥段：男主必须付出**可见代价**+真诚补偿弧线，不能一个道歉就和好 |
| 重生/穿越 | Second chance / regression | 欧美已跑通；规则须在 EP1-2 用视觉建立（闪回/对照画面），不靠 VO 解说 |
| 契约婚姻 | Marriage of convenience | 已验证高转化；付费墙前必须出现第一个"假戏真做"信号 |
| 白月光/替身 | Stand-in bride / lookalike | 替身**自我意识觉醒**是欧美改法核心（联动女性意识维度），不能一直甘当影子 |
| 离婚冷开局 | "Divorce first" 开场 | EP-01 直接从离婚/背叛现场开场，已验证高转化开局 |
| 狼人等级/命定伴侣 | Pack rank + Fated mates + "I reject you" 拒绝仪式 | 圈层共识台词与等级体系是亚文化设定维度的命门（Agent 10 考据对象） |

### 必做本地化清单

1. **人名/地名/机构**：全部改为欧美语境（Li Wei → Liam；集团→ corporation/empire；某市→ NYC/小镇名）
2. **对白去 Chinglish**：不逐字翻译原著对白，按"对白=行动"规则用英语思维重写；俚语查真实用法
3. **行为动机校验**：孝道绑架、面子文化、辈分服从等动机欧美观众无法共情 → 替换为利益、爱、自由、复仇等普世动机
4. **文化雷区过滤**：对照 `reviewers-scoring.md` 欧美雷区清单逐章扫描原著情节，命中即改写或删除
5. **女性意识校验**：女主每个关键节点是否"独立决策"？原著里被动接受的桥段改为主动选择（哪怕选错）

## 0.5 产出：adaptation-map.md（原著对照表）

> 写入项目根目录。阶段1 写大纲时对照它取材；Aligner 的"大纲承诺兑现"维度引用它检查改编偏离度。

```markdown
# 原著对照表 (Adaptation Map)

## 改编决策摘要
- **原著**: [书名]，[N]万字，[题材]
- **project_type**: [类型] | **集数**: [N] | **Premise**: [4选1 + 改造说明]
- **砍掉的支线**: [列表+理由]
- **合并的角色**: [A+B→C，理由]
- **补写的内容**: [原著没有但短剧需要的：DI信息差/爽点/广告素材爆点]

## 集 ↔ 原著章节映射

| 集 | Block | 原著章节 | 处理 | 备注 |
|----|-------|---------|------|------|
| EP-01 | 1 | 第3章（激励事件） | 改写 | 从冲突现场开场，第1-2章背景删除，用DI补 |
| EP-02 | 1 | 第4-5章 | 保留 | 建立DI-01 |
| EP-03 | 1 | 原创 | 新增 | 原著爽点密度不足，补打脸 |
| ... | | | | |

处理类型：**保留**（情节照搬+本地化）/ **改写**（结构重组）/ **新增**（原著没有）/ **删除**（在此登记被砍内容，防止后期误引用）

## 原著卖点保护清单

> 改编再激进，这些原著核心卖点不能丢（丢了就不是这本书的改编了）：
1. [卖点1，对应集数]
2. [卖点2，对应集数]
```
