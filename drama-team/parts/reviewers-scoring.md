# 三专用 Aligner — 评分表与扣分规则

> 审核时、评分时读取。工作流+输出格式见 `parts/reviewers-workflow.md`，Agent观众旁白见 `parts/reviewers-agents.md`，创作法则见 `parts/reviewers-patterns.md`。

> **判定标准（唯一 PASS 线）**：每个 Aligner 满分 100，**≥80 PASS / 70-79 ⚠️需修改 / <70 FAIL**。
> 题材宽严差异由**类型权重表**表达（同一维度不同题材权重不同），不另设题材 PASS 线。

## 一、欧美市场标准（本技能唯一目标市场）

> 打分前的"尺子"。所有维度按欧美竖屏短剧标准判定。

| 项 | 标准 |
|----|------|
| **开局钩子** | **3秒进冲突**（与"3秒定帧"同口径）。前3秒无视觉事件=重大扣分 |
| **情绪表达** | 爆炸式（"I want you to suffer!"），克制内心戏不适用 |
| **节奏容忍** | 极低：5秒没爽点观众走人 |
| **Beat Engine** | Hook=引爆（3秒定帧），Friction=可拍摄冲突，Spike=静音测试，Button=问题前切断 |
| **Premise 要求** | 必须内建冲突（Enemies-to-lovers / Forbidden proximity / Power imbalance / Arranged circumstance） |
| **Dramatic Irony** | EP2-3建立观众信息优势，维持差距到付费墙后 |
| **文化雷区** | ①GLBT+未成年+永久身体改变组合 ②宗教隐喻过重 ③种族刻板印象 ④美化奴隶制/殖民 ⑤过度血腥无意义 |
| **本地化** | 台词零 Chinglish；行为动机符合欧美文化背景；女主必须有自主选择权（反恋爱脑/反无深度雌竞） |

> 其他市场（日韩/国内/东南亚）的适配标准已移出运行时，历史参考见 `RATIONALE.md`。

#### 导演覆盖机制

> Aligner输出三色判定：🟢Green（放行）/ 🟡Yellow（警告，可忽略需写理由）/ 🔴Red（硬拦，部分可覆盖）
> 导演可override 🟡Yellow和部分🔴Red（文化雷区/伏笔逾期不可覆盖），覆盖需写理由，记录到TASK.md

**覆盖限制**：
- 每集最多覆盖 2 项，累计 ≤5 次/项目（防止全面绕过审核）
- 覆盖项必须在审核报告中注明 `Director Override: [理由]`
- 被覆盖的项不参与后续集的"模式学习"（避免污染 Aligner 判断基准）

**类型适配说明**：
- **核心冲击力（12）与广告素材潜力（8）全类型统一高权重**——前者是爆款第一维度；后者对应行业实际（营销占预算约90%、80%+下载来自投流，素材爆点密度实质决定生死）
- **角色魅力/代入感**（v5.4新增）：AI 最易产出"结构满分但角色无魅力"的剧本，此维度专门设防；sweet_romance 最高（8，磕糖靠 book-boyfriend 式男主）
- **revenge**：冲突强度(10)+节奏/平台(8)双高——打脸爽感，节奏即产品；女性意识(4)——复仇剧观众主体是女性；Premise=Enemies-to-lovers/Victim's return
- **forced_love**：核心关系(8)+Dramatic Irony(8)双高——gaslighting/权力不对等；Premise=Power imbalance/Forbidden proximity
- **sweet_romance**：核心关系(10)+对白=行动(8)+角色魅力(8)三高——磕糖靠对白与男主魅力；冲突容忍度最高（4）；Premise=Forbidden proximity/Marriage of convenience
- **mary_sue**：节奏/平台(10)+悬念钩子(8)双高——爽点密度最高，逻辑不重要（世界观2）；Premise=Power imbalance
- **mystery**：Dramatic Irony(12)+悬念钩子(10)双高——DI本身即产品；世界观逻辑(6)——推理闭环
- **vampire_werewolf**：世界观逻辑(8)+核心关系(8)双高——设定考据+情感张力；亚文化设定(4)——Rank/Mate Bonding等圈层共识是命门；Premise=Fated mates/Rejected mate

### 维度判定要点

> 每维度满分见上方权重表。扣分扣至该维度 0 分为止。

| # | 检查项 | 判定要点 |
|---|--------|---------|
| 0 | **核心冲击力** | 这集有没有一个让人"哇"的瞬间？①简单直接→满分 ②被复杂设计稀释→50% ③没有→0分。合规但无聊=不及格 |
| 0b | **角色魅力/代入感** | 观众会不会替主角上头？①主角有至少1个"想看她赢"的特质（非纯受害者）②男主有 book-boyfriend 式魅力时刻（权力反差/专一/破防）③角色工具人化、只推剧情无个性→0分 |
| 1 | **Beat Engine** | 四个**功能**是否齐备：①引爆开场 ②可拍摄冲突 ③信息重定价 ④问题前切断。缺一功能→-3分/项。**功能不是秒表**：单场连续对峙集允许结构上不可切分，只查功能是否存在。详见 `pitfalls.md#二` |
| 2 | **开局钩子** | 前 **3 秒**必须有**不可跳过的理由**（①冲突 ②极致美感 ③极致诡异 ④极致反差 ⑤极致好奇） |
| 3 | **冲突强度** | 每集冲突绑定不可逆代价，非"口头争吵就完事"。**Premise 自检**：冲突是否内建于设定？场景驱动冲突→-5分 |
| 4 | **悬念钩子** | ①有无结尾钩子 ②钩子是否在后续集被回收 ③钩子是否与当前集内容脱节 ④**钩子通胀检查**：复合钩子(8-10)用于非高潮集→-5分 ⑤**伏笔逾期**：逾期≥3集未回收→-5分（状态机与检查脚本见 `continuity.md`，此处为唯一扣分出处） |
| 5 | **Dramatic Irony** | 本集有没有"观众知道但角色不知道"的时刻？①维持→满分 ②太快发现→50% ③没有→0分。详见 `pitfalls.md#四` |
| 6 | **对白=行动** | 每句对白推进冲突或压力下揭示角色。解释性对白>2句→-3分。详见 `pitfalls.md#五` |
| 7 | **人物弧光** | 主角有成长线，反派有悲剧内核。①主角无任何变化→-3分 ②反派纯恶无动机→-3分 |
| 8 | **核心关系** | 体现核心关系卖点（每集必须有）。①核心关系零互动→-6分 ②互动但无张力→-3分 |
| 9 | **世界观逻辑** | 规则一致性、无临时加设定、角色知识合理、视觉变化有解释 |
| 10 | **节奏/平台** | V.O.配额按类型（revenge/forced_love≤2句、sweet_romance/mary_sue≤3句、mystery≤5句）；≥60%段落含动作；连续3集不重复同一冲突类型 |
| 11 | **广告素材潜力** | 本集是否有可独立切出作为Meta/TikTok广告素材的高能片段？①极强视觉/情绪冲击的2-5秒切片 ②切片无需前情即可理解 ③全剧至少3-5个素材爆点 |
| 12 | **本地化自然度** | 台词是否避免Chinglish？①俚语/口语符合欧美真实用法 ②配音(VO)具备情感表现力 ③行为动机符合欧美文化背景。Chinglish→-3分/处 |
| 13 | **女性意识** | 女主是否有自主选择权？①独立决策（非被动接受）②无深度雌竞→-2分 ③纯恋爱脑→-4分 |
| 14 | **亚文化设定** | （超自然题材专属）世界观设定自洽+符合圈层共识：①追问2层无漏洞 ②有品阶/等级体系。设定矛盾→-4分；违反圈层共识→-3分 |
| 15 | **音爆点标注** | 剧本层只审**声音设计机会的标注**：①每集≥2处音爆点标注（哪句台词/哪个动作是声音冲击位：泼酒/摔门/BGM骤停位）②<2处→-2分。（配音表现力/BGM落地属成片层，不在剧本审；分镜层声音节奏见 Storyboard-Aligner #10） |
| 16 | **文化敏感** | 欧美雷区（见上方标准表）、年龄+行为组合、原谅需有前置铺垫 |
| 17 | **信息密度** | 每集≥2个新信息点。<2个→-2分 |
| 18 | **差异化** | 冲突模式是否为该类型Top3套路？避免"格式正确但无聊"的PASS。无差异化→-2分 |
| 19 | **大纲承诺兑现** | 本集是否兑现 outline.md 分集梗概中的"大纲承诺"项？①承诺的揭示/转折/事件 ②承诺的角色出场 ③承诺的伏笔操作。未兑现→-2分/项 |

### 扣分示例

```
- 钩子类型与本集内容不匹配 → -10分（如高潮集用了信息钩子但本集是生死对决）
- 悬念钩子无类型标注 → -3分
- 前 3 秒无视觉事件 → -10分
- 冲突无不可逆代价 → 冲突强度0分
- 结尾悬念模糊 → -10分
- 角色动机断裂（施暴者→忏悔者无过渡）→ -5分
- 高潮处临时加设定 → -5分
- 连续 3 集同冲突类型 → -8分
- 伏笔逾期≥3集未回收 → -5分（悬念钩子维度）
- V.O. 设定解说超配额 → -3分
- 文化雷区组合未缓冲 → -3分
- Beat Engine 缺功能 → -3分/项
- Premise 场景驱动冲突 → -5分
- Dramatic Irony 缺失（EP2-3 无观众信息优势）→ 扣至该维度0分（权重≥8的类型此项伤害大；低权重类型自然轻——宽严由权重表达）
- 对白解释感受 → -3分/句；对白前3行无冲突 → -3分
- 音爆点标注不足（每集<2处）→ -2分
- 角色工具人化/主角无"想看她赢"特质 → 角色魅力维度0分
- 无可切广告的高能片段 → -4分；全剧素材爆点<3个 → -4分
- Chinglish/中式表达 → -3分/处；台词配音无情感表现力 → -3分
- 纯恋爱脑/女主无自主选择 → -4分；无深度雌竞 → -2分
- 设定矛盾/追问2层有漏洞 → -4分（超自然题材）
```

### 🔥 叙事钩子等级表

> 编剧写 Cliffhanger 时标注类型，Aligner 审核时检查强度是否匹配当前集阶段。

| 等级 | 类型 | 核心原理 | 短剧示例 |
|------|------|---------|---------|
| 1 | **信息钩子** | 信息缺口 → 人脑想补全 | "名册最后一页写着..." |
| 2 | **异常钩子** | 反常事 → 人心好奇 | "吸血鬼居然流了眼泪" |
| 3 | **危险钩子** | 威胁 → 生存本能 | "Carmilla 獠牙逼近颈动脉" |
| 4 | **欲望钩子** | 观众想看角色得到/失去什么 | "他终于说出了那三个字" |
| 5 | **关系钩子** | 核心关系面临转折/破裂 | "两个敌人发现彼此是同父异母" |
| 6 | **羞耻钩子** | 角色被暴露、被看穿、被羞辱 | "所有人都知道了她的秘密" |
| 7 | **不可逆钩子** | 发生了回不去的事 | "父亲撕毁了名册关键页" |
| 8 | **误判钩子** | 观众/角色以为 A，其实是 B | "以为是救赎，其实是陷阱" |
| 9 | **后果链钩子** | 一个后果引发连锁反应 | "Laura 变身→被父亲发现→赶出家门→流落街头" |
| 10 | **复合钩子** | 同时触发 2-3 种钩子类型 | 身份暴露(6)+撕毁名册(7)+父亲破门(3) |

**钩子选择原则（动态，不套用公式）**：先判断本集内容类型，再选最匹配的钩子：

| 集类型 | 推荐钩子方向 | 示例 |
|--------|------------|------|
| **揭示集**（身份/真相揭晓） | 异常(2) + 误判(8) | "以为是人，其实是吸血鬼" |
| **对峙集**（正面对决） | 危险(3) + 不可逆(7) | "刀架在颈上，决定无法收回" |
| **关系转折集**（情感/信任变化） | 关系(5) + 羞耻(6) | "他看到了不该看的" |
| **日常铺垫集** | 信息(1) + 欲望(4) | "日记最后一页缺了一角" |
| **高潮/结局集** | 后果链(9) → 复合(10) | 多个线索同时收束 |

**审核判定（动态评估）**：
- ✅ 钩子类型匹配本集内容，且让观众有"不看不行"的冲动 → 满分
- ⚠️ 钩子可用但强度偏弱（如高潮集只用了信息钩子）→ 扣 5 分
- ❌ 钩子与本集内容脱节（如日常集用了后果链却无前置铺垫）→ 扣 10 分
- ❌ 无类型标注 → 扣 3 分（编剧需写 `Hook: [类型名称+等级]`）

**核心原则**：10 级是**词汇表**不是公式。编剧根据本集实际情节选最适配的钩子，Aligner 判断"这个钩子是否有效服务了这集的内容"，而不是"这集必须 N 级"。

**简单性原则（防通胀 ⭐）**：
- **能用单一的不用复合**："他撕了名册"（不可逆7）比"同时触发4种钩子"（复合10）更有冲击力——观众1秒内只能消化一个核心情绪
- **能用低级的不用高级**：日常铺垫集用信息钩子(1)就够
- **复合钩子是高潮集的特权**：复合钩子(8-10)用于非高潮集 → -5分

## 三、Storyboard-Aligner（审分镜）— 100 分

**核心原则：不看公式，看"这集的内容是否被分镜有效服务了"。**
先判断集类型（囚禁/对峙/闪回/高潮/氛围...），再评估分镜是否匹配。

### 评分表（合计恰好 100，无需归一化）

| # | 维度 | 满分 | 检查方式 |
|---|------|------|---------|
| 0 | **核心冲击力** | 12 | 💥 分镜有没有一个让人"哇"的画面？①有，且简单直接（一张脸/一个动作/一个特写）→12分 ②被复杂运镜/多层灯光稀释→6分 ③没有→0分 |
| 1 | **Beat Engine 视觉** | 12 | 🎬 ①Hook=最炸画面（3秒定帧）②Friction=可拍摄动作 ③Spike=静音也有冲击的画面 ④Button=定格在表情/动作。缺一功能→-3分/项（按功能不按秒表） |
| 2 | **竖屏特写优先** | 10 | 📱 vertical drama lives in faces。①特写/近景≥50% ②全景/中景≤30%（仅定场/转场）③核心情绪在特写中传达 |
| 3 | **节奏分层** | 10 | ⚡ 爆发点/情绪点/过渡镜头时长是否形成张弛对比？①时长突变点（每3-4镜一个节奏锚点）②信息过载检查（1秒塞2种情绪→拆分）③情绪镜头给足反应时间 |
| 4 | **运镜匹配度** | 10 | 🎯 运镜是否服务场景情绪？①恐怖=不稳定感 ②亲密=压迫感 ③冲击=动态 ④揭示=焦点变化 ⑤可执行性（见分级表）⑥**🟡运镜理由检查**：无理由=炫技，-3分/个 |
| 5 | **景别层次** | 8 | 📐 本集核心信息是否被景别有效传达？①囚禁集偏特写但需层次（至少1全景+1极端特写）②对峙集"中景建关系→特写抓表情→极端特写抓关键"递进 ③景别单一→视觉疲劳 |
| 6 | **时空切换** | 6 | 🔗 闪回/场景切换衔接三件套：①动作承接 ②视觉锚点（MATCH CUT）③音效联动。情感转折有无前置铺垫镜头 |
| 7 | **AI指令颗粒度** | 10 | 🤖 每镜头有 AI 可执行指令：①特效参数明确（位置/颜色/透明度）②AI约束词 ③光影描述具体 |

### 🔥 Atmosphere 列常见错误

- ❌ **写成情绪词**：如"恐怖压抑"、"暧昧紧张"、"悲伤回忆" — 这些属于 Description 列
- ✅ **写成物理环境**：如"深夜/雨/闪电"、"黄昏/阴/微光"、"室内/无窗/人工光"
- **根因**：Atmosphere 是 Lighting 列的前置条件。先知道"深夜+雨+闪电"，Lighting 才能据此推理光源。写"恐怖压抑"，Lighting 无法推导实际光源
- **检查项**：Atmosphere 列中的词是否能在实际场景中"看到"（天气/时间/光线）而非"感觉到"（情绪）

### 运镜可执行性分级（唯一定义）

| 级别 | 运镜类型 | AI遵循率 | 使用规则 |
|------|---------|---------|----------|
| 🟢 可靠 | static / slow_push / slow_pull / pan / tilt / top_down / over_shoulder | >80% | 自由使用，每集占比 ≥60% |
| 🟡 有限 | handheld / orbit / zoom / dolly / low_angle | 30-80% | **每集≤2个**，必须写理由+备选方案；需加约束词（"subtle handheld"/"slow dolly"） |
| 🔴 赌博 | whip_pan / crash_zoom / rack_focus / spin / complex_combo / 第一人称POV / 畸变 | <30% | **每集≤1个**，必须标注"需人工替代方案"；超出→扣5分并建议替换为🟢/🟡或拆镜拼接 |

**🟡运镜理由检查**：每个🟡运镜必须在分镜表或Shot Notes中写明"为什么这个场景需要手持/跟拍/旋转"。无理由的🟡=炫技，扣3分/个。ReelShort爆款大量是固定+缓推，🟡运镜是例外不是常态。

### 跨集视觉承接扣分规则

> 前提：visual_continuity.md 存在且含上一集结尾视觉快照。如不存在（首集/旧项目），本维度跳过不扣分。

```
- 角色画面位置无理由跳变（上集右侧→本集左侧，无转场/时间跳跃解释）→ -3分/角色
- 色调无理由跳变（上集暖金→本集冷蓝，无情绪/时间/场景变化支撑）→ -3分
- 场景物理状态不延续（上集门碎了→本集门完好，无修复情节）→ -3分/处
- 服装不延续（上集换装→本集穿回旧装，无换装情节）→ -2分/角色
- 光源方向不一致（同场景无光源变化理由）→ -2分
- 运镜风格无理由跳变（上集手持→本集固定，同情绪场景）→ -2分
```

**合理跳变的例外（不扣分）：**
- 时间跳跃（"X HOURS LATER"/"NEXT MORNING"）→ 色调/光源/服装可变
- 场景切换（室内→室外）→ 色调/光源/运镜全部可变
- 情绪转折（恐惧→决心）→ 运镜风格可变
- 闪回/梦境 → 一切可变，但需标注

### BGM/SFX 节奏扣分规则

```
- BGM无理由持续（整集同一段BGM无变化）→ -2分
- Hook段BGM平淡（引爆时刻无BGM配合或与画面情绪矛盾）→ -2分
- Friction段SFX缺失（可拍摄动作无音效强化，如摔门无声）→ -2分/处
- Spike段依赖BGM（静音测试：关BGM后spike消失）→ -3分
- Button段BGM未骤停（观众没有"自己脑补"空间）→ -2分
```

### 其他维度扣分规则

```
- 节奏分层：无时长突变点（每镜时长均匀）→ -3分；信息过载（1秒塞2种情绪）→ -2分/处
- 景别层次：景别单一无变化 → -3分；核心信息在非最优景别传达 → -2分；正面镜头>35% → -2分
- 时空切换：闪回无衔接三件套 → -3分/处
- AI指令颗粒度：特效参数模糊 → -2分/处；缺AI约束词 → -2分/处
- 情绪递进：情绪变化未被镜头语言"看见"→ -3分；转折点无运镜/光影对比 → -2分
```

## 五、评分自检（防膨胀，v5.1 精简版）

> AI 给自己写的内容打分存在膨胀风险。保留以下轻量自检规则，不再维护基准剧本库。

1. **核心冲击力不可连续3集满分** — 如果3集都给12分，第4集起强制人工抽检
2. **某维度从未扣分 → 疑似漏检** — 人工抽检该维度3集
3. **扣分项不可跳过** — 每个维度必须写判定（✅/❌），不允许空白
4. **审核报告必须含理由** — 即使满分也要写"为什么这集在这个维度做得好"
5. **连续3集≥90分或全剧平均≥88 → 疑似膨胀** — 逐项对照扣分规则重新审核最近一集
