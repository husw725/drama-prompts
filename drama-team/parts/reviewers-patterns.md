## 六、常见陷阱

| # | 陷阱 | 解决 |
|---|------|------|
| 1 | 跨集衔接断裂 | 每集写完检查下集开场是否回收 |
| 2 | 只用单一视角评审 | 十视角（按激活策略）+ 对应 Aligner |
| 3 | 标准过于模糊 | 量化评分 + 具体扣分理由 |
| 4 | 缺乏优先级 | 🔴🟡🟢 分级处理 |
| 5 | 套用公式审分镜 | 先判断集类型，再动态评估 |
| 6 | 对英文剧名用国内人设 | 先确认市场，再切换人设 |
| 7 | 审核员 context 包含编剧意图 | 只看成品，不包含意图说明 |
| 8 | 悬疑强剧情路线 | 海外观众"不花钱也能忍" |
| 9 | 忽略声音 | 声音是海外用户付费的核心驱动因素 |
| 10 | 忽略文化差异 | 闪婚失忆（结婚证无照片）、撒红酒 vs 泼咖啡 |
| 11 | **Hook 写成铺垫** | 3秒定帧：陌生人不需要前情就能理解画面 |
| 12 | **Friction 写成情绪暗示** | 必须可拍摄：物理/语言冲突，不是"气氛紧张" |
| 13 | **场景驱动冲突** | Premise自检：设定是否自动产生冲突？ |
| 14 | **Dramatic Irony 缺失** | EP2-3必须建立观众信息优势 |
| 15 | **对白解释感受** | 行动/否认/转移，观众推断 |
| 16 | **全景过多** | 竖屏=特写优先，特写/近景≥50% |
| 17 | **Button 解释太多** | 在问题前切断，比安全早2秒 |
| 18 | **全量跑10个Agent** | 按激活策略按需调用，标题评审只需5个 |
| 19 | **忽略付费墙卡点** | Agent 08 必检：情绪高峰是否踩在EP8/10卡币位置 |
| 20 | **无广告素材爆点** | Agent 09 必检：全剧是否有3-5个可切广告的高能切片 |
| 21 | **世界观设定出戏** | Agent 10 必检：垂直赛道设定是否符合海外圈层共识 |
| 22 | **恋爱脑/雌竞无独立线** | Agent 04 必检：女主遭遇背叛时是否有独立选择 |
| 23 | **Chinglish/文化水土不服** | Agent 07 必检：台词本地化自然度+配音表现力 |
| 24 | **男频打脸节奏慢** | Agent 02 必检：前5分钟是否有高潮冲突+反击时间差 |

## 短剧创作法则

> 核心法则详见 `pitfalls.md`（爆款第一原则 + Beat Engine + Premise + DI + 对白=行动 + 炫技防控 + 竖屏/声音硬规则）

### 通用法则
- 每集必有冲突，节奏紧凑（3秒没冲突就划走）
- 爽点分布合理，人物动机清晰，伏笔埋设与回收完整
- **钩子匹配** — 结尾 Cliffhanger 根据本集内容类型动态选择最适配的钩子（参考10级体系），每集标注 `Hook: [类型+等级]`
- **短句驱动** — 动作描述 ≤ 2 个分句，用独立短句替代复杂从句
- **情感锚点例外** — 关键转折点保留 1-2 句长描写作情感厚度
- **格式标准** — 连续对话用 (CONT'D)，集末 FADE TO BLACK/OUT，全剧 FADE OUT + THE END
- **对话风格一致性** — 根据项目风格设定，不混用

## 审核通过关键要素

### 1. Beat Engine 四段完整
- ✅ **Hook**: 3秒定帧，引爆不是铺垫（"他掐住她的下巴"而不是"她走进房间"）
- ✅ **Friction**: 可拍摄冲突，不是情绪暗示（"他把文件摔在桌上"而不是"气氛紧张"）
- ✅ **Spike**: 静音测试通过（画面本身有冲击力，不依赖音效/配乐）
- ✅ **Button**: 在问题前切断，比感觉安全早2秒（切在睁大眼睛的瞬间，不是"她惊恐地发现..."）

### 2. Premise 自带冲突
- ✅ **Enemies-to-lovers**: 角色天然对立，同框就有张力
- ✅ **Forbidden proximity**: 被迫共处但不该在一起，每次互动有重量
- ✅ **Power imbalance**: 权力不对等，每个指令/服从都有压力
- ✅ **Arranged circumstance**: 非自愿连接，没有选择本身就是冲突
- ❌ **场景驱动**: 每集临时加误会/谎言/巧合 → 93集撑不住

### 3. Dramatic Irony 活跃
- ✅ EP2-3 建立观众信息优势（让观众看到主角看不到的事）
- ✅ 差距在维持（角色接近真相又拉回）
- ✅ 揭秘时机在付费墙后（观众为"她什么时候才发现"付费）
- ❌ 角色太快发现真相（Dramatic Irony 窗口太短）

### 4. 对白=行动
- ✅ **冲突前2行就进入**
- ✅ **角色不解释感受** — 行动/否认/转移（"她把戒指扔进垃圾桶"而不是"I feel so betrayed"）
- ✅ **Subtext>Text** — 没说的比说了的更有力
- ✅ **短促为主** — 长独白极少有效

### 5. Face-slap 必须直接暴力
- ✅ **有效**: 泼红酒、推搡、抢物品、肢体冲突
- ❌ **无效**: 口头嘲讽、眼神不屑、翻白眼

### 6. 情感表达必须爆炸式
- ✅ **有效**: "我要你生不如死！"、"你是我的！"、"我找了你三年！"
- ❌ **无效**: "对不起"、"谢谢你"、"是你..."

### 7. Cliffhanger 必须明确
- ✅ **有效**: "Montana 见，我的真爱在那里等你"（发件人：Trent）
- ❌ **无效**: "她不知道，这次旅行将改变她的一生..."

### 8. 危机 - 救援结构
- ✅ **有效**: 巨熊拍向旋翼 → 变身救场 → 认出女主
- ❌ **无效**: 巨熊出现 → 消失 → 男人出现（缺乏戏剧张力）

### 9. 典型迭代次数
- **EP-01**: 通常 3 次（需要建立冲突模式+Premise验证）
- **EP-02**: 通常 4 次（需要建立人物关系+Dramatic Irony信息优势）
- **EP-03 后**: 通常 2-3 次（模式已建立）

### 6. 三件套工作流实战教训（2026-04-29 Carmilla项目验证）

**三件套 = 剧本(script/) + 分镜(storyboard/) + AI Prompts(prompts/)**

**第一稿高频翻车点（EP-02首次68分、EP-06首次70分）：**
| 翻车点 | 表现 | 修复后效果 |
|--------|------|-----------|
| 核心关系缺席 | Carmilla零出场/零台词/零情绪关联 | 加入闪回+矛盾心理台词（EP-06: 70→98） |
| 开局依赖上集回收 | 前3秒只是"上集紫纹门缝闪过" | 改为主动视觉冲击（EP-07 v2: 琥珀瞳孔发光开场） |
| 冲突无不可逆代价 | Carmilla闪避、紫纹自然扩散 | 父亲撕毁名册关键页（永久性信息丢失） |
| 无具体倒计时 | 只有"情况在恶化" | 明确"7天倒计时"+"3天内来人" |
| 对白过多 | 19句/集（EP-02 v1） | 压缩到12-15句，每句都有信息量 |
| 正面镜头超标 | 50%+（EP-02 v1） | 用仰拍/俯拍/过肩替代，控制在≤35% |
| 角色外观漂移 | Carmilla瞳色在不同集之间变化 | **v2.0: 用 manifest.md 强制锁定** |

**分镜硬规则（写前检查，避免返工）：**
- 镜头数按集类型：氛围16-18 / 标准18-22 / 恐怖20-24 / 高潮22-25
- 单镜≤5秒（悬念慢推结尾最长10秒）
- 正面镜头≤35% — 优先用仰拍/俯拍/过肩/跟拍
- 运镜种类≥5种 — 最少覆盖：推/侧面/正面+3种其他
- 对白12-15句/集

**审核员Prompt关键设计：**
- 审核员context中**不要包含**编剧的意图说明——只看成品
- 如果上轮审核FAIL，第二轮必须在context中标注上轮扣分项
- 审核员输出"修改建议"时，编剧不要逐条执行——挑核心硬伤修改

**效率提升技巧：**
- 写分镜前先在脚本中标注每个time slot的scene和action
- Prompts文件不需要等审核通过再写——可以三件套一次性写完，然后统一审
- 审核FAIL时重写：保留通过审核的部分，只修改扣分项对应段落
