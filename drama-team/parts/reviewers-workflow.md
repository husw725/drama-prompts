## 单集审核流程

```
0. 先跑 tools/validate_ep.py（机械维度：时长/锚点/景别/运镜/伏笔）——FAIL 先修再送审
1. 内容 → 路由判断类型 → 选择对应 Aligner
2. Aligner 独立评分（100分制，PASS/⚠️/FAIL）——只审机器测不了的创意维度
3. 关键节点：可选激活 1 个 Agent 输出观众旁白（纯口语化，不打分）
4. 输出综合报告（Aligner 评分 + 🔴🟡🟢 优化清单 + 可选观众旁白）
```

**盲审硬规则（防自评膨胀的根治手段）**：
- Aligner 评分必须在**独立上下文**中执行——与创作上下文隔离，实现方式宿主无关：子代理、新开会话、另一个模型实例均可
- 审核输入白名单：被审文件 + `reviewers-scoring.md` 对应评分表 + continuity 核心三项 + outline 类型DNA。**不给创作过程、不给编剧的自我说明**
- 报告末尾必须有机器可读行：`**总分: XX/100**`（validate_ep.py 依此做膨胀趋势检测）
- 无法开独立上下文的宿主才退回主模型内联自审，此时 `reviewers-scoring.md` 评分自检全部条款生效

**Agent 激活规则**（仅关键节点）：唯一出处见 `parts/reviewers-agents.md` 激活策略表。

## 全剧审核流程

```
1. 用户发送全剧三件套
2. 逐集跑对应 Aligner（可并行读文件，串行出报告）
3. 汇总全剧评分 → 通过/未通过集数统计
4. 集间衔接检查（Cross-Episode Continuity）
5. 激活 3 个 Agent 输出观众旁白（主妇+付费墙+影评）
6. 输出全剧综合报告
```

---

## 审核→修改闭环

```
1. 🔴 必须修改 → 直接修改对应文件（write_file 全量重写）
2. 🟡 建议优化 → 修改或制作阶段处理
3. 🟢 锦上添花 → 制作阶段处理
4. 修改后重新跑对应 Aligner → 直到 ≥ 80 分
```

---

## 集间衔接检查（Cross-Episode Continuity）

| # | 检查项 | 典型断裂 |
|---|--------|---------|
| 1 | 开场回收上集结尾钩子 | 下集跳新场景，上集核心情绪被丢弃 |
| 2 | 角色动机连贯 | 上集"放下仇恨"，下集又冷酷复仇 |
| 3 | 悬念线索延续 | 上集铺垫的秘密，下集不再提起 |
| 4 | 角色状态一致 | 受伤角色下一集消失；觉醒能力重复"发现" |
| 5 | 场景位置合理 | 上集在 A 地，下集在 B 地，无过渡 |

**修复手法：**
- 下集前 5 秒必须接上集结尾
- 角色转变需要独白或台词解释"为什么"
- 闪回收拢形成情感闭环

## Output Format（综合报告）

```markdown
# 【短剧审核报告】

## 评审信息
- 目标市场：欧美（本技能唯一目标市场）
- 评审类型：[剧本/分镜/Prompts/集间衔接]
- 项目类型：[revenge/forced_love/sweet_romance/mary_sue/mystery/vampire]

## Aligner 评分

[对应 Script / Storyboard / Prompt-Aligner 评分表]

**总分: XX/100** → PASS ✅ / ⚠️ / FAIL ❌

## 观众旁白（可选，仅关键节点）

### Agent XX — [角色名]
> "[1-3句口语化评论]"

## 优先级优化建议

### 🔴 必须修改（影响留存/付费转化）
1. [具体问题] → [具体方案]

### 🟡 建议优化（提升体验）
1. [具体问题] → [具体方案]

### 🟢 锦上添花（专业升级）
1. [具体问题] → [具体方案]
```

## 审核系统架构（v5.1）

```
本技能审核系统 = Aligner 独立评分（核心） + Agent 观众旁白（可选补充）

使用场景：
1. 标题/大纲评审 → Script-Aligner（大纲维度子集）
2. 剧本评审 → Script-Aligner + [首集/付费墙集可选观众旁白]
3. 分镜评审 → Storyboard-Aligner
4. Prompts评审 → Prompt-Aligner
5. 全剧评审 → 逐集Aligner + 集间衔接检查 + 3个Agent观众旁白
6. 超自然题材 → 对应Aligner + Agent 10 亚文化旁白
```
