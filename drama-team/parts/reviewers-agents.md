# 十视角评审团 — 观众旁白模式（v5.1）

> **v5.1 变更**：Agent 从评分系统降级为**观众旁白**（纯口语化评论，不打分、不聚合、不交叉验证）。
> 评分由 Aligner 独立完成，Agent 只提供"真实观众会怎么说"的直觉补充。
> 详见：`parts/reviewers-scoring.md`（Aligner评分表+扣分规则）、`parts/reviewers-workflow.md`（工作流+输出格式）、`parts/reviewers-patterns.md`（创作法则+实战教训）

---

## 设计理念

| | v5.0（旧） | v5.1（新） |
|---|-----------|-----------|
| Agent 角色 | 评分系统（100分制+维度+权重+锚点） | 观众旁白（口语化评论，不打分） |
| Agent 激活 | 逐集3人/关键集5人/全剧10人 | 逐集0人/关键集1人/全剧3人 |
| 交叉验证 | \|Agent分-Aligner分\|>15→⚠️ | **删除**（单评分系统，天然一致） |
| 聚合公式 | 加权平均+极值惩罚 | **删除** |
| 校准机制 | 基准剧本库+偏严/膨胀/Agent间校准 | 仅保留 Aligner 基准校准 |
| Token 消耗 | ~100% | ~30-40% |

**核心逻辑**：Agent 的价值不在打分，在于"不同观众会怎么感受"。Aligner 已经吸收了所有关键维度，Agent 评分与 Aligner 高度冗余。保留观众视角的直觉价值，去掉评分冗余。

---

## 激活策略（⭐ 大幅精简）

> 逐集审核**不激活 Agent**，Aligner 独立完成评分。
> 仅在关键节点激活 1-3 个 Agent 输出观众旁白，补充创作者直觉。

| 场景 | 激活 Agent | 理由 |
|------|-----------|------|
| **逐集常规审核** | 无 | Aligner 独立评分，足够 |
| **首集** | Agent 03 GenZ | 3秒完播率是首集生死线，口语化反馈最有价值 |
| **付费墙集（EP8/EP10）** | Agent 08 付费墙精算师 | 付费转化是商业底线，需要冷酷数据视角的口语化判断 |
| **全剧审查** | Agent 01 主妇 + Agent 08 付费墙 + Agent 05 影评 | 情绪+商业+逻辑三个最关键视角 |
| **超自然题材全剧** | + Agent 10 亚文化死忠 | 世界观考据是垂直赛道命门 |

**不再按 project_type 动态选人**——逐集不激活，关键节点固定选最有价值的1-3个。

## 观众旁白输出格式

> **关键**：纯口语化，不打分，不写维度表。就像一个真实观众看完后的即时反应。

```markdown
### 观众旁白（Agent XX — [角色名]）

> "[1-3句口语化评论，聚焦该Agent最关心的1-2个问题。如果这集在该Agent视角下没问题，可以只写一句肯定。]"
```

**示例**：

```markdown
### 观众旁白（Agent 03 — GenZ）

> "首集3秒hook有了，但第4个镜头开始对白空转了2句，我可能就划了。建议第4镜直接切到她发现抽屉里那封信。"

### 观众旁白（Agent 08 — 付费墙精算师）

> "EP8情绪峰值踩在卡币位置，完美。但EP9开头如果3秒内不回收'他掐住她下巴'这个画面，我赌40%用户会划走——付费墙后第一集的留存比首集还重要。"
```

## Industry Ground Truth

> 详见 `parts/reviewers-scoring.md` 欧美市场标准 + `parts/pitfalls.md` 爆款原则。
> Agent 写旁白时隐式引用以下核心洞察：

- 越简单直接越受欢迎（之桃影视朱古力）
- 声音是付费驱动因素（朱古力实地观察）
- Beat Engine 是欧美爆款核心结构（Filmustage 2026）
- Premise-Driven Conflict > 场景驱动冲突（Bound by Honor 373M views）
- Dramatic Irony 是最强留存机制（Miss You After Goodbye 双平台#1）
- 3-7-21 付费墙 Block 分层（ReelShort/DramaBox 2025）
- 竖屏=特写优先（Filmustage 2026）
- Cliffhanger 写到秒（ReelShort工程团队）
