## 审核模式（⭐ 按剧类型动态选Agent）

> **逐集轻量审核（3 Agent），全剧完成后跑一次全量审核（10 Agent）。**
> 轻量3个不是固定的——根据项目类型从10个Agent中选最匹配的3个。

### 轻量模式：按剧类型选3人（⭐ 逐集默认）

> **选人规则**：每个Agent有适配类型标签，项目启动时根据 `outline.md` 的 `project_type` 匹配，选得分最高的3个。**08付费墙始终入选**（商业底线不可妥协）。

| project_type | 首选3人 | 理由 |
|-------------|--------|------|
| **revenge** 复仇 | 02工人 + 05影评 + 08付费墙 | 工人=打脸爽点雷达，影评=逻辑闭环 |
| **forced_love** 强制爱 | 01主妇 + 04高知女性 + 08付费墙 | 主妇=情感代入，高知=反恋爱脑审查 |
| **mary_sue** 玛丽苏 | 01主妇 + 03GenZ + 08付费墙 | 主妇=代入感，GenZ=3秒完播率判官 |
| **mystery** 悬疑 | 05影评 + 10亚文化 + 08付费墙 | 影评=逻辑硬伤，亚文化=设定考据 |
| **werewolf/vampire** 超自然 | 10亚文化 + 01主妇 + 08付费墙 | 亚文化=世界观考据(最高优先)，主妇=情感 |
| **sweet_pet** 甜宠 | 01主妇 + 03GenZ + 08付费墙 | 主妇=磕糖代入，GenZ=节奏不耐 |
| **comedy** 喜剧 | 03GenZ + 02工人 + 08付费墙 | GenZ=梗/节奏，工人=爽点密度 |
| **默认/未指定** | 01主妇 + 05影评 + 08付费墙 | 情绪+逻辑+商业，覆盖面最广 |

**选人算法**：
```
1. 08付费墙 固定入选（商业底线）
2. 按 project_type 查上表，取前2个非08的Agent
3. 如项目跨类型（如 revenge+forced_love），取两个类型的首选并集，去重后按适配分排序取前2
4. 结果写入 TASK.md 的「审核配置」章节，全剧沿用
```

### Industry Ground Truth (基于真实数据)

这些洞察来自 2025-2026 年海外短剧行业数据：

**什么有效 ✅**
| 洞察 | 来源 |
|------|------|
| 越简单直接越受欢迎 — 玛丽苏 > 复杂剧情 | 之桃影视制片人朱古力 |
| 声音是付费驱动因素 — 气泡音/骚讲话 | 朱古力实地观察 |
| 女频全球通吃 — 核心受众是拉丁裔/东南亚社会下层女性 | 36氪 2025Q1 |
| 黑帮 + 狼人题材火爆 — "强制爱 + 身份觉醒"组合 | 2025年2月市场数据 |
| 情感陪伴 > 剧情深度 — 观众要的是情绪价值，不是逻辑 | 之桃影视 2024 复盘 |
| **Beat Engine (Hook→Friction→Spike→Button) 是欧美爆款核心结构** | Filmustage 2026, ReelShort制作方 |
| **Premise-Driven Conflict > 场景驱动冲突** — 设定自带冲突93集不崩 | Bound by Honor (373M views) |
| **Dramatic Irony 是最强留存机制** — 观众知道角色不知道 | Miss You After Goodbye (双平台#1) |
| **对白=行动，Subtext>Text** — 角色不解释感受，观众推断 | Filmustage 2026 |
| **3-7-21 付费墙 Block 分层** — >50%付费转化率 | ReelShort/DramaBox 2025 |
| **竖屏=特写优先** — vertical drama lives in faces, not locations | Filmustage 2026 |
| **Cliffhanger 写到秒** — Button 在55-58秒freeze-frame最优 | ReelShort工程团队 |

**什么踩坑 ❌**
| 踩坑 | 原因 |
|------|------|
| 悬疑/强剧情路线行不通 | 观众"不花钱也能忍" |
| 精致但不爽 — 百万美金制作但数据不好 | 竖屏限制 + 观众耐心有限 |
| 闪婚失忆认不出老公 | 海外结婚证没有照片 |
| 自助洗衣房场景 | 海外不常见 |
| 过度"虐女"情节 | 海外女性观众反感 |
| **Hook 写成铺垫**（"她走进房间"而不是"他掐住她的下巴"） | 3秒定帧失败，观众划走 |
| **Friction 写成情绪暗示**（"气氛紧张"而不是"他把文件摔在桌上"） | 不可拍摄，画面没在干活 |
| **Spike 依赖音效**（静音后 spike 消失） | 那是音量不是冲击 |
| **Button 解释太多**（"她惊恐地发现..."而不是切在她睁大眼睛的瞬间） | 比安全早2秒切断 |
| **场景驱动冲突**（每集临时加误会/谎言/巧合） | Premise 不自带冲突，93集撑不住 |

### 节奏公式（行业验证 ⭐ Beat Engine 化聚）

```
Hook(引爆) → Friction(可拍摄冲突) → Spike(重新定价) → Button(问题前切断)
```

> 行业原话："Draft your timestamp skeleton first — 0:00 ignition, 0:32 first jolt, 1:18 spike, 1:50 button — then write the dialogue that carries those moments." (Filmustage 2026)
> ReelShort 工程团队发现：freeze-frame 在 55-58 秒时留存率最高，编剧现在写到秒而不是写到页。
